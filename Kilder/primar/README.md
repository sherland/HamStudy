# Arkiverte primærkilder

Denne mappen inneholder lokale, daterte kopier av versjonssensitive
primærkilder. Filene er dokumentasjonskopier; gjeldende originalkilde skal
alltid kontrolleres før juridiske eller operative opplysninger brukes.

Metadata, originaladresser og kontrollsummer føres i
[`../KILDEREGISTER.md`](../KILDEREGISTER.md).
